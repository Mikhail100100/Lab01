## Решение :

## Часть 1. Создание сети и проверка настроек коммутатора по умолчанию
### Нужно использовать консольное подключение для первоначальной настройки коммутатора потому что другими способами (другими подключениями) произвести первоначальную настройку коммутатора не получитсяэ
### Первоначальное подключение "чистого" коммутатора через Telnet  невозможно потому что не настроен transport input telnet и настройка каналов виртуального соединения для удаленного управления (vty)
### Изучая текущий файл running configuration мы видим интерфейсов FastEthernet - 24, а Gigabit Ethernet - 2,диапазон значений, отображаемых в vty-линиях от 0 да 15
### Файл загрузочной конфигурации (startup configuration) пустой, система нам об этом сообщает startup-config is not present
### Изучая характеристики SVI для VLAN 1 мы видим такие выходные данные:
![Снимок экрана 2025-05-01 133954](https://github.com/user-attachments/assets/27000b24-e724-4b7d-ae3a-2346c2c5ca6e)
### Данный интерфейс выключен  
### Изучая сведения о версии ОС Cisco IOS на коммутаторе мы видим версию 15.0(2)SE4 под управлением которой работает коммутатор
### Файл образа системы назван как System image file is "flash:c2960-lanbasek9-mz.150-2.SE4.bin" 
### Далее изучаем свойства по умолчанию интерфейса FastEthernet0/6, данный интерфейс включен
![image](https://github.com/user-attachments/assets/77236c82-627f-44a2-9faa-b789a1692f04)

### Имя присвоено образу Cisco IOS 2960-lanbasek9-mz.150-2.SE4.bin
